# Analisi del Festival di Sanremo (1951–2023)

## Descrizione

Dashboard realizzata con Google Looker Studio per analizzare l'evoluzione del Festival di Sanremo tra il 1951 e il 2023 attraverso tre dataset differenti.
È possibile esplorare la dashboard interattiva al seguente link: 
https://datastudio.google.com/reporting/63179aa3-7f73-487d-a304-bf1fec2e1d1e/page/p_4bt13zev5d

## Obiettivi

- analizzare l'evoluzione del Festival;
- analizzare l'evoluzione delle canzoni in gara;
- integrare dati provenienti da Spotify mediante Data Blending.

## Dataset

- Festival
- Classifica
- Spotify

## Tecnologie utilizzate

- Google Looker Studio
- Google Sheets
- Data Blending
- Filtri interattivi
- Scorecard
- Serie temporali
- Grafici a barre
